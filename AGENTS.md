# Agent instructions

## SC7Labs agent handoff

Codex, Claude and other agents: read and maintain one local `.agent/HANDOFF.md` for this project. Keep it concise: current progress, decisions, test evidence, blockers and the next executable step. Create it locally if absent, update during work and before handoff. Do not duplicate progress reports or flood PR discussions; keep PR descriptions and comments brief and reviewer-focused.

Warn when usage limits approach if possible, but continue working normally. Never package `.agent/` in customer releases or commit private handoff contents to public/potentially public Git history; sync privately across clones as needed. Preserve existing project rules and historical PRs.
